# Download & Convert - Windows

[English](windows.en.md)

Встановлення, налаштування та використання з **Linux-контейнерами Docker Desktop**. Виконуйте команди PowerShell **по одній, згори вниз**. Не копіюйте позначки запрошення на зразок `PS ...>` або `>>`. Інтерфейс підтримує **English / Українська**.

## 1. Встановіть потрібні програми

1. Встановіть [Git for Windows](https://git-scm.com/install/windows).
2. Перевірте [вимоги Docker Desktop](https://docs.docker.com/desktop/setup/install/windows-install/): підтримувана 64-бітна Windows, увімкнена віртуалізація в BIOS/UEFI та щонайменше 8 ГБ оперативної пам'яті. Відкрийте PowerShell **від імені адміністратора**, виконайте `wsl --install` і перезавантажте комп'ютер. Якщо WSL уже встановлено, виконайте `wsl --update`.
3. Встановіть і відкрийте [Docker Desktop](https://docs.docker.com/desktop/setup/install/windows-install/). Використовуйте **WSL 2 engine** та **Linux containers**. Дочекайтеся запуску рушія. Якщо Docker призупинено, виберіть **Resume / Unpause**.
4. Відкрийте нове звичайне вікно PowerShell і перевірте:

```powershell
git --version
docker compose version
docker run --rm hello-world
```

Очікується `Hello from Docker!`. Python, Node.js і FFmpeg уже входять до образу платформи; окремо встановлювати їх не потрібно.

## 2. Виберіть папку та завантажте проєкт

Виберіть **будь-яку зручну папку** в Провіднику. Відкрийте її, натисніть адресний рядок, введіть `powershell` і натисніть Enter. PowerShell відкриється у вибраній папці. Потім виконайте:

```powershell
git clone --branch main https://github.com/Denofix/youtube-downloader.git
Set-Location .\youtube-downloader
Invoke-Item .
```

Git створить вкладену папку `youtube-downloader`. Залиште PowerShell у ній, поруч із `compose.yaml` і `Dockerfile`. Редактор коду не потрібен. Якщо використовуєте вже відкритий термінал, перед клонуванням перейдіть до вибраної батьківської папки; шлях із пробілами беріть у лапки. Якщо проєкт уже завантажено, відкрийте його наявну папку та скористайтеся розділом оновлення.

## 3. Налаштуйте та запустіть

```powershell
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
docker compose config --quiet
docker compose up -d --build --wait
docker compose ps
Invoke-RestMethod http://localhost:8080/api/health
Start-Process "http://localhost:8080"
```

Дочекайтеся завершення першої збірки й завантаження залежностей. Мають працювати обидва сервіси: `api` та `worker`. Відповідь перевірки стану має містити `status = ok` і `worker_online = True`. Якщо обробник ще запускається, повторіть запит за кілька секунд. Відкрийте [http://localhost:8080](http://localhost:8080).

Щоб змінити конфігурацію, відкрийте `notepad .env`, збережіть файл і знову виконайте `docker compose up -d --build --wait`.

| Параметр | Типове значення | Призначення |
| --- | --- | --- |
| `PORT` | `8080` | Локальний порт сайту; для `8081` відкривайте `http://localhost:8081` |
| `MAX_FILE_BYTES` | `536870912` | До 512 МіБ на файл |
| `MAX_STORAGE_BYTES` | `5368709120` | До 5 ГіБ медіафайлів у сховищі |
| `RESULT_TTL_SECONDS` | `86400` | Зберігання файлів протягом 24 годин |
| `JOB_TIMEOUT_SECONDS` | `1800` | До 30 хвилин на одне завдання |

Налаштування показують значення сервера; змінювати їх потрібно у `.env`. Для звичайного використання ключі API не потрібні. Доступ залежить від публікації та платформи. Типово сервіс доступний лише на цьому комп'ютері.

## 4. Користуйтеся платформою

Праворуч угорі виберіть **English / Українська**. Браузер запам'ятає вибір.

| Розділ | Що робити |
| --- | --- |
| **Завантаження** | Вставте посилання на одну публічну публікацію YouTube, TikTok, Instagram або Pinterest чи трек SoundCloud. Натисніть **Аналізувати посилання**, виберіть формат, якість або елементи та додайте завантаження до черги. Кілька вибраних елементів також доступні в ZIP. |
| **Завдання** | Дочекайтеся стану **Завершено**, завантажте результат і відкрийте його. Тут можна скасувати або повторити завдання, перевірити строк зберігання чи надіслати збережений файл до конвертера. |
| **Конвертація** | Завантажте один локальний файл, дочекайтеся перевірки та виберіть перетворення: відео зі звуком у MP3, PNG у WebP або відео в короткий GIF. Налаштуйте бітрейт чи параметри GIF і додайте завдання до черги. |
| **Налаштування** | Перевірте стан обробника, версії інструментів, ліміти та використання сховища. |

Почніть із короткого відео та невеликого зображення. Перевірте зображення і звук у відео, рух у GIF і вміст ZIP. Для MP3 потрібна аудіодоріжка. Збільшення бітрейту не відновлює втрачену якість. Пакетне завантаження, сканування каналів/профілів і списки відтворення поки не підтримуються.

## 5. Оновлення, зупинка та повторний запуск

Відкрийте PowerShell **у наявній папці проєкту**, залиште Docker Desktop запущеним і виконайте в такому порядку:

```powershell
git fetch origin
git switch main
git pull --ff-only
docker compose up -d --build --wait
```

Натисніть **Ctrl+F5**. Після змін у роботі з джерелами проаналізуйте посилання знову. Перед перемиканням збережіть локальні зміни Git; не видаляйте їх через `reset --hard`.

За потреби виконуйте ці команди окремо:

```powershell
docker compose stop
docker compose up -d --wait
docker compose logs --tail 80 api worker
```

Вони відповідно зупиняють сервіси, запускають їх знову та показують останні логи. Історія й файли зберігаються в постійному Docker-томі. `docker compose down` залишає його, а **`docker compose down -v` видаляє дані**.

## 6. Усунення проблем

| Симптом | Дія |
| --- | --- |
| `Docker Desktop is manually paused` | Виберіть Resume / Unpause у Docker Desktop і повторіть запуск |
| `no configuration file provided` | Відкрийте корінь проєкту; перевірте `Test-Path .\compose.yaml`. Оновіть Git перед збіркою |
| `unknown flag: --buildgit` | Вставляйте команди окремими рядками: `--build` і `git fetch` належать до різних команд |
| Не відкривається шлях із пробілами | Візьміть весь шлях у лапки або відкрийте PowerShell із потрібної папки в Провіднику |
| Порт зайнятий | Виберіть вільний `PORT` у `.env`, перестворіть сервіси та відкрийте нову адресу |
| Завдання залишаються в черзі | Перевірте `worker_online`, сервіс `worker` і логи |
| Інтерфейс виглядає застарілим | Дочекайтеся успішної збірки та натисніть Ctrl+F5 |

Для розбору проблеми збережіть текст помилки, вивід `docker compose ps` та останні логи. [Репозиторій](https://github.com/Denofix/youtube-downloader) · [Матриця конвертера](../media-service/converter-matrix.md) · [Експлуатація та резервні копії](../media-service/operations.md).
