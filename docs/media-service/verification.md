## Owner verification — first live scenario passed

On 11 November 2026, the owner reported that the service works and supplied screenshots from the Windows localhost:8080 instance. The evidence includes:

- YouTube metadata, actual format choices and a selected 1080p / 25 FPS / MP4 option with audio.
- Completed real download tasks, saving the MP4 and playback in the owner's native player.
- A direct MP3 192 kbps result visible in the download folder, supported by the owner's success report.
- Detected MP4 input metadata, MP3 extraction at 192 kbps, a completed conversion and the converted MP3 save dialog.

The first real download and conversion gate is therefore accepted for this tested setup. This is owner-provided live evidence, separate from the controlled CI checks and the failed development-network attempt. It does not establish support for every YouTube link, other platforms, or every conversion combination.
